# Budget-Management-System
A web-based budget management application that allows users to track and manage their personal incomes and expenses. Built as the final project for CSE470 - Software Engineering at BRAC University.<br> App Link: https://budget-management-s5yw.onrender.com

**Course Information**<br>

Course Code:	CSE470<br>
Course Name:	Software Engineering<br>
Group:	Group 4<br>
Members:	Mashrafi, Ismaeel, Mahajabin, Esha

**Features**<br>

- User registration and login with secure password hashing<br>
- Session-based authentication with JWT support<br>  
- Add, view, and manage income and expense records<br>
- Dashboard with financial summaries<br>
- Automated scheduled tasks using cron jobs<br>
- Email notifications via Nodemailer<br>
- Input validation for data integrity<br>
- Responsive UI built with Bootstrap 5<br>

**Tech Stack**<br>

**Backend**<br>

- Runtime: Node.js (v20.17.0)<br>
- Framework: Express.js<br>
- Database: MongoDB (via Mongoose)<br>
- Authentication: bcrypt, JSON Web Tokens (jsonwebtoken), express-session, cookie-parser<br>
- Email: Nodemailer<br>
- Scheduler: node-cron<br>
- Validation: validator<br>
- Other: dotenv, method-override, axios<br>

**Frontend**<br>

- Templating Engine: EJS with ejs-mate<br>
- Styling: Bootstrap 5, CSS<br>
